# SHOP Polymer App

A responsive e-commerce website clone built using HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Pages

- Home Page
- Product Listing Page
- Product Details Page
- Cart Page
- Checkout Page

## Features

- Responsive design for mobile, tablet, and desktop
- Navigation bar with cart icon
- Product categories and product images
- Product listing with prices
- Product details with size selection
- Cart page with quantity and price details
- Checkout page with shipping and payment sections
- Responsive layouts using CSS media queries

## Responsive Breakpoints

- Mobile: Below 768px
- Tablet: 768px and above
- Desktop: 1024px and above
- Large Desktop: 1024px and above

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Use Live Server to run the project locally.
